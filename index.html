Settings

      On Auto, each message is rated from 1 to 5 and goes to the lowest-level model that is switched on and meets the rating. Each model shows its level and the ratings it is used for; set a level yourself to change that.

      Models are loaded with all the context they can take. A big window needs a lot of memory, so set a limit if models load slowly or fill your memory.

      Each thread works in a container built from this image, with Git added. Left empty, each workspace gets the image its own files ask for — a Node image for a package.json, a Python one for a pyproject.toml, and so on — so that the project's own tests and builds can be run. Threads in a workspace share what their package managers download, and keep their installed dependencies to themselves.
